# Bernstein — Poll Application on Kubernetes

Deployment of the multi-service **Poll** application (`poll`, `worker`, `result`, `Redis`, `PostgreSQL`) on Kubernetes.

## Project Structure

- `poll-application/` — Source code and Dockerfiles for `poll`, `worker`, and `result`, plus `schema.sql`.
- `k8s/` — Kubernetes manifests *(coming next)*.
- `scripts/` — Automation scripts for build, push, and deployment *(coming next)*.
